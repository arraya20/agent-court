# Agent Instructions

Sebelum mengerjakan tugas:

1. Periksa skill yang relevan di `.agents/skills/`.
2. Gunakan skill yang sesuai dengan jenis tugas.
3. Baca `SKILL.md` sebelum mengubah kode.
4. Jalankan validasi atau test setelah perubahan.
5. Jangan menggunakan semua skill sekaligus jika tidak relevan.
